# 02 · 临汾废弃矿山生态修复工程

> 依托项目：山西黄河重点生态区（临汾）历史遗留废弃矿山生态修复示范工程
> 我的工作：矢量数据处理与统计口径统一、生态修复单元汇总、公众问卷结果可视化

## 背景

临汾是山西重要的煤炭与铁矿开采区，长期开采留下大量历史遗留废弃矿山。示范工程要做的是**把零散的矿山图斑归并成可实施的生态修复单元**，并为每个单元配置修复措施与投资。

我的工作偏「搭底座」：图斑数据的格式转换、按县/单元归并、面积与指标统计，供方案书引用。

### zh.py — 格式转换

外部提供的数据常是 GeoJSON，ArcGIS 工作流更适合文件地理数据库（`.gdb`）。脚本封装了 GeoJSON → Feature Class 的转换，并处理字段名截断（shapefile 字段名 10 字符限制）与中文编码问题。

### 合并同类项.py — 图斑归并

不同县、不同批次交上来的图斑字段名不统一（有的叫「县名」，有的叫「所属县区」），需要先归一再合并。脚本做了两件事：

1. **字段映射**：把各来源的同类字段映射到统一字段名
2. **文件名合法化**：中文名直接做 shp 文件名会出现非法字符，脚本用正则清洗保留中文数字字母：

```python
def clean_filename_for_shp(name, prefix="m_"):
    name = re.sub(r'[\\/:*?"<>|]', "_", str(name))
    name = re.sub(r"\s+", "_", name)
    ...
```

### 矢量处理-2.ipynb — 分县统计

核心是把图斑按县汇总：读取「临汾市投影.shp」的属性表，确认代表县名的字段（不同来源字段名不同，脚本顶部有专门提示），再分组统计面积、图斑数、按修复类型分类汇总。输出表格直接进方案书。

### 问卷出图.py — 公众参与可视化

示范工程要求公众参与，问卷回收后要出统计图。这个脚本解决的是一个很实际的问题：**Matplotlib 中文乱码**。用多级字体回退（`SimHei` → `Microsoft YaHei` → `Arial Unicode MS` → `PingFang SC`）兼容 Windows / macOS。

## 运行环境

- **ArcGIS Pro Python 3.11**（`zh.py`、`合并同类项.py`、`矢量处理-2.ipynb` 需要 `arcpy`）
- `问卷出图.py` 只需 `matplotlib` + `numpy`

## 产出

- 归并后的生态修复单元矢量与属性表

## 备注

这类项目的难点不在算法，而在**数据口径**：同一批图斑，不同县交上来的字段名、坐标系、编码各不相同。脚本里大量的字段映射与文件名清洗逻辑，就是为这个准备的。
