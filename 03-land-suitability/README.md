# 03 · 全国油茶种植适宜性评价

> 目标：在全国尺度上评价油茶（*Camellia oleifera*）种植适宜性，划定 7 个主产省的适宜区，并提取 158 个油茶生产重点县
> 技术栈：Rasterio、GeoPandas、NumPy（纯开源栈，不依赖 ArcPy）

## 方法框架

```
气候因子  ┐
土壤因子  ├→ 隶属度函数标准化（0~1）→ 加权叠加 → 综合适宜性栅格
地形因子  ┘                                      ↓
                                    分省分割 → 重点县提取 → 统计与制图
```

核心是**隶属度函数**：不同因子对油茶生长的响应曲线不同，不能统一做 min-max 归一化。

| 因子 | 隶属函数类型 | 说明 |
|---|---|---|
| 年均温、降水等气象要素 | 抛物线型 | 存在最适区间，过高过低都扣分 |
| 部分土壤/气候指标 | 反 S 型 | 单向递减，越好越接近 1 |
| 坡度 | 反 S 型 | 越陡越不适宜 |
| 坡向 | 自定义分段 | 阳坡优于阴坡 |

## 目录与脚本

```
03-land-suitability/scripts/
├── 气象隶属度.py        气象因子（2000–2020 逐年 tif，6 波段）→ 隶属度
├── 土壤隶属度.py        土壤属性 → 隶属度
├── 地形隶属度.py        DEM 求坡度坡向 → 隶属度（含抛物线型/反S型函数定义）
├── 综合适宜性.py        三因子栅格重采样对齐 → 加权叠加成综合适宜性
├── 裁剪.py              按研究区矢量批量裁剪
├── 分省.py              按 7 省分割栅格、筛选区县、提取 158 个重点县
├── 发展潜力.py          重点县指标统计 → 发展潜力分级
├── 重点县表格.py        重点县属性表整理（对标论文表 4）
├── tr.py                栅格统计与表格导出

```

### 关键实现点

**1. 栅格对齐（`综合适宜性.py`）**

三个因子的来源分辨率不同，直接叠加会错位。脚本用 `rasterio.warp.reproject` 把土壤、地形统一重采样到气候图层的网格（`Resampling` 可选双线性/最邻近），并用气候图层作为参考 transform：

```python
target_res = None   # None = 沿用气候图层分辨率；也可指定 1000 表示统一到 1 km
```

**2. 坡向隶属度（`地形隶属度.py`）**

坡向是 0–360° 的环形变量，不能线性映射。脚本按方位分段给分，避免 359° 和 1° 被当成两端极值。

**3. 重点县提取（`分省.py`）**

先按省界切割综合适宜性栅格，再与全国区县矢量做空间筛选，最后按名单提取 158 个油茶生产重点县——这一步是为了把「栅格上的适宜性」落到「行政单元可执行的布局建议」。

## 数据说明

| 数据 | 来源 / 形式 | 是否入库 |
|---|---|---|
| 气象数据 | 2000–2020 逐年 tif，每年 6 个波段（Camellia_Climate 数据集） | 否（体积大） |
| 土壤属性 | 栅格，分辨率低于气候层 | 否 |
| DEM | 用于提取坡度、坡向 | 否 |
| 区县矢量 | 全国区县边界 + 7 省界 | 否 |
| 重点县名单 | 158 个油茶生产重点县 | 见 `重点县表格.py` 中的名单 |

数据总量约 770 MB，未纳入仓库。
