# 07 · Python 实用脚本集

日常处理数据和写论文时攒下来的一批小脚本，定位是「解决一个具体问题」，改几个路径就能直接用。

文件名前的编号是分类序号，不是执行顺序（彼此独立）。

## 数据采集

| # | 脚本 | 作用 | 说明 |
|---|---|---|---|
| 01 | `01_B站评论爬取.py` | 抓取 B 站视频评论区，支持分页与限速，输出 JSON | 需要登录态 Cookie |
| 02 | `02_河南年鉴PDF爬取.py` | 抓取河南统计年鉴网页，按年份批量下载 PDF 并分目录保存 | requests + BeautifulSoup |

`01_B站评论爬取.py` 的 Cookie 需自己从浏览器 F12 复制，**原文件里的真实 Cookie 已删除**：

```python
headers = {
    'Cookie': '<请填入你自己的 Cookie>',   # ← 在这里填
}
```

> 这类 Cookie 等同于账号凭证，不要提交到仓库或发给任何人。

## 图像处理

| # | 脚本 | 作用 | 关键参数 |
|---|---|---|---|
| 03 | `03_图片转字符画.py` | 图片转 ASCII 字符画，按灰度映射到字符集 | `WIDTH` 字符画宽度、`CHARS` 字符集 |
| 04 | `04_批量裁剪图片.py` | 同一组像素参数套用到整个文件夹的图片 | `crop_values = (left, top, right, bottom)` |
| 05 | `05_多图拼版.py` | 多图按行列自动排版成一张（论文插图常用） | 每组张数 / 行数 / 列数 / 底部留白 |

`05_多图拼版.py` 三个数字决定版式：

```python
IMAGES_PER_GROUP = 3   # 每组几张
ROWS, COLS = 1, 3      # 1 行 3 列
BOTTOM_PADDING = 0     # 底部留白
```

## 文件管理

| # | 脚本 | 作用 |
|---|---|---|
| 06 | `06_批量压缩文件夹.py` | 多进程批量压缩（`ProcessPoolExecutor` 并发调 WinRAR），整理大量成果文件夹时用 |
| 07 | `07_导出目录结构.py` | 图形界面选目录，输出树形结构文本，写方案书/论文的目录说明直接粘贴 |

`07_导出目录结构.py` 用 tkinter 选目录，`allowed_exts` 可限定只收录特定扩展名，避免把中间文件也列进目录树。

## GIS 辅助

`08_属性字段中英翻译.py` —— 把 shp 属性表里的中文字段批量翻译成英文（做英文标注地图时用）：

```
arcpy 读取字段值 → 百度翻译 API 批量翻译 → 写回新字段
```

脚本用缓存去重，避免同一个地名重复调接口。**APPID 与密钥已替换为占位符**，需自行到[百度翻译开放平台](https://api.fanyi.baidu.com/)申请。

## 依赖

```bash
pip install requests beautifulsoup4 pillow
```

`08_属性字段中英翻译.py` 额外需要 `arcpy`（ArcGIS Pro 环境），其余脚本标准库即可。

## 关于路径

所有脚本顶部的路径已改为相对路径（如 `r"年鉴"`、`r"学习用"`），运行前按实际位置修改。脚本里没有保留任何个人目录、用户名或账号信息。

## 这些脚本的价值

不是工程化的库，但每个都对应一个真实的小痛点：年鉴 PDF 一页页手点太慢、几十张图裁剪参数一样却要重复操作、论文插图要拼成三列版式、中文字段做英文地图得一个个改。写这类脚本的习惯，比脚本本身更有用。
