# 07 · Python 实用脚本集

日常处理数据和写论文时攒下来的一批小脚本，都是「只为自己解决一个问题」的定位，所以直接跑、改几个路径就能用。

## 脚本一览

### 数据采集

| 脚本 | 作用 | 依赖 |
|---|---|---|
| `b站爬评论.py` | 抓取 B 站视频评论区（分页、限速、按视频 BV 号批量），输出 JSON | requests |
| `河南年鉴爬虫.py` | 抓取河南统计年鉴网页并按年份批量下载 PDF，目录结构化保存 | requests、beautifulsoup4 |

`b站爬评论.py` 需要登录态 Cookie。**原文件里的 Cookie 已删除**，运行前需自己从浏览器 F12 复制：

```python
headers = {
    'Cookie': '<请填入你自己的 Cookie>',   # ← 在这里填
}
```

> 这类 Cookie 等同于账号凭证，任何情况下都不要提交到仓库或发给别人。

### 图像处理

| 脚本 | 作用 |
|---|---|
| `图片转字符.py` | 图片转 ASCII 字符画，按灰度映射到字符集，可调宽度 |
| `cut.py` | 批量裁剪：同一组像素参数套用到整个文件夹的图片 |
| `pintu.py` | 多图拼版：按「每组几张 / 行数 / 列数」自动排版成一张图，常用于把零散插图拼成论文版式 |

`pintu.py` 的排版参数就是三个数：

```python
IMAGES_PER_GROUP = 3   # 每组几张
ROWS, COLS = 1, 3      # 1 行 3 列
BOTTOM_PADDING = 0     # 底部留白
```

### 文件管理

| 脚本 | 作用 |
|---|---|
| `压缩.py` | 多进程批量压缩（`ProcessPoolExecutor` 并发调用 WinRAR），用于整理大量成果文件夹 |
| `读取目录.py` | 图形界面选目录 → 输出树形结构文本，写方案书/论文的目录说明时直接用 |

`读取目录.py` 用 tkinter 做目录选择，`allowed_exts` 可配置只收录特定扩展名，避免把一堆中间文件列进目录树。

### GIS 辅助

`字段翻译.py` —— 把 shp 属性表里的中文字段批量翻译成英文（制图需要英文标注时用），流程是：

```
arcpy 读取字段值 → 百度翻译 API 批量翻译 → 写回新字段
```

脚本里用拼音/随机串做缓存去重，避免同一个地名重复调用接口。**APPID 与密钥已替换为占位符**，需要自己去[百度翻译开放平台](https://api.fanyi.baidu.com/)申请。

## 依赖

```bash
pip install requests beautifulsoup4 pillow
```

`字段翻译.py` 额外需要 `arcpy`（ArcGIS Pro 环境）。其余脚本标准库即可。

## 关于路径

所有脚本顶部的路径已改为相对路径（如 `r"年鉴"`、`r"学习用"`），运行前按自己电脑的实际位置修改。脚本里没有保留任何个人目录、用户名或账号信息。

## 这些脚本的价值

不是工程化的库，但每个都对应一个真实的小痛点：年鉴 PDF 一页页手点太慢、几十张图裁剪参数一样却要重复操作、论文插图要拼成三列版式、中文字段做英文地图时得一个个改。写这类脚本的习惯，比脚本本身更有用。
